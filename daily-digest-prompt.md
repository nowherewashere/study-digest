# Промпт для ежедневной сводки по учёбе

Локальная задача Claude Code Desktop, ежедневно в 9:00. Рабочая папка задачи —
корень учебной директории, тот каталог, внутри которого лежит `digest/`.
Текст ниже вставляется целиком в поле **Instructions**.

Пути в промпте относительные, от рабочей папки задачи, — чтобы его можно было
отдать другому человеку вместе с `digest/`. Промпт предполагает вокруг себя
ровно три вещи: `digest/` с программой, каталог `<код предмета>/` на каждый курс
из `config.env` и `stash/` внутри него под методички. Больше ничего.

Что настраивается отдельными файлами, без правки промпта:

- какие курсы смотреть — строки `COURSE` в `digest/config.env`;
- как выглядит ответ — `digest/daily-digest-template.md`;
- порядок сдачи работ — раздел «Порядок сдачи лабораторной работы» в `CLAUDE.md`
  корня учебной директории, если он там есть; у каждого он свой.

---

Собери сводку по учёбе. Работай молча, итог выдай одним сообщением по-русски.

Все пути ниже — от рабочей папки задачи.

1. Запусти `digest/study state --json`. Одна команда отдаёт всё: дедлайны с датой, временем и состоянием ответа, просроченное, обновления в курсах с прошлого запуска, новые задания, сдвиги сроков, тесты впереди, баллы, а также состояние локальных репозиториев — собранные PDF отчётов и презентаций, теги, релизы на GitVerse и SourceCraft, незакоммиченное. Список курсов берётся из `config.env`; других курсов в ТУИС не касайся, там висят старые. Ничего в ТУИС не отправляй.

2. Разбери JSON, не пересчитывая ничего заново. Даты уже готовы: у каждого срока есть `text` (`ДД.ММ ЧЧ:ММ`), `full` (с годом) и `left` («2 дн 5 ч»). Поле `errors` — то, что получить не удалось; если оно непустое, скажи об этом одной строкой, а не молчи. Поле `labs[].tuis.matched_by: "number"` означает, что работа сопоставлена с заданием ТУИС по номеру в названии — это догадка, так и говори.

3. Если в `tuis.updates` есть записи с непустым `files` — забери их: `digest/study files <код курса> --pull` для каждого затронутого курса. Файлы лягут в `<код>/stash/`, скачиваются только документы до 50 МБ, уже имеющиеся пропускаются. В сводке назови, что появилось.

4. Для работ из `tuis.not_started` посмотри методичку в `<код предмета>/stash/` и разберись, что там делать. Порядок сдачи — `digest/lab-submission.md`; если в корне рабочей папки есть `CLAUDE.md` со своим разделом про сдачу, он главнее. Чего нет ни там, ни там — не выдумывай.

5. Оформи ответ строго по шаблону `digest/daily-digest-template.md`. Сам работу не начинай — только предложи следующий шаг.

6. Если ничего не горит и обновлений нет — скажи это в двух строках, не выдумывай активность.

Ориентируйся на текущее время: срочность считается от момента запуска, а не запланированного времени рутины.
